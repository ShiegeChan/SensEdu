This directory (SensEdu/src/cmsis) contains a subset of the Arm CMSIS-DSP
library, bundled with SensEdu so that the signal-processing examples build
without requiring a separately installed CMSIS-DSP library.

  Component : CMSIS-DSP (Digital Signal Processing library)
  Upstream  : https://github.com/ARM-software/CMSIS-DSP
  Version   : Taken from the CMSIS-DSP V1.10.1 package release. Upstream keeps

              changes, so the bundled files span V1.9.0 to V1.10.1. See the

Bundled files
-------------

  arm_fir_f32.c            arm_math_types.h        none.h
  arm_fir_init_f32.c       basic_math_functions.h  support_functions.h
  arm_math_memory.h        fast_math_functions.h   utils.h
                           filtering_functions.h

Only the floating-point FIR filter implementation and its transitive
headers are included. All other CMSIS-DSP sources were omitted, not
altered.


Modifications made by the SensEdu project
-----------------------------------------

Per clause 4(b) of the Apache License, the following changes were made to
the files listed above. Each modified file also carries an in-file notice.

  * Include paths were flattened: `#include "dsp/<name>.h"` was changed to
    `#include "<name>.h"`, because the bundled subset is kept in a single
    flat directory rather than the upstream `dsp/` layout.

    Affected files: arm_fir_f32.c, arm_fir_init_f32.c,
    basic_math_functions.h, fast_math_functions.h, filtering_functions.h,
    support_functions.h

  * No algorithmic, numerical, or API changes were made.

  * arm_math_memory.h, arm_math_types.h, none.h and utils.h are byte-for-byte
    identical to upstream.
